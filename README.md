# Neighbourly

Bay Area neighbourhood analyser — demographics, housing, schools, map choropleths, social sentiment, and AI chat across 6 counties (Alameda, Contra Costa, Marin, San Francisco, San Mateo, Santa Clara).

## Stack

- Next.js 14, TypeScript, Tailwind CSS
- MapLibre GL JS + react-map-gl (Carto Positron base map)
- D3.js (color scales, tooltip charts, sparklines)
- Zustand (global state)
- Supabase (API response cache + curated neighbourhood layer)
- Claude API (chatbot + sentiment)
- Reddit API (Social Pulse)

## Getting started

```bash
npm install
cp .env.example .env.local
# Add CENSUS_API_KEY at minimum; others enable caching, social, and chat
npm run build:tracts   # downloads TIGER data, emits tract GeoJSON + index
npm run seed:neighbourhoods   # assigns Fremont tracts to 6 curated neighbourhoods
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Neighbourhood layer

User-facing identity comes from the Supabase `neighbourhood` table (Fremont 6 districts seeded first). Census tracts remain the internal data engine for map choropleths; sidebar stats are population-weighted aggregates when a neighbourhood is selected.

Without Supabase configured, Fremont neighbourhoods are served from `src/data/fremont-neighbourhoods.json` (generated by the seed script).

```bash
npm run seed:neighbourhoods   # writes SQL + static JSON fallback
```

Apply [`supabase/migrations/002_neighbourhood.sql`](supabase/migrations/002_neighbourhood.sql) and [`supabase/seed/fremont-neighbourhood-tract.sql`](supabase/seed/fremont-neighbourhood-tract.sql) for production.

## Environment variables

See [`.env.example`](.env.example). Minimum for local dev:

| Variable | Required for |
|----------|----------------|
| `CENSUS_API_KEY` | Live Census ACS data (falls back to county medians without it) |
| `NEXT_PUBLIC_SUPABASE_URL` + `SUPABASE_SERVICE_ROLE_KEY` | Response caching + neighbourhood layer |
| `ANTHROPIC_API_KEY` | AI chatbot + sentiment analysis |
| `REDDIT_CLIENT_ID` + `REDDIT_CLIENT_SECRET` | Optional — OAuth Reddit search; without these, Social Pulse uses public Reddit RSS |

Run [`supabase/schema.sql`](supabase/schema.sql) in your Supabase project before enabling cache.

## Deploy (Vercel)

1. Push to GitHub and import in Vercel
2. Add all env vars from `.env.example`
3. Run `npm run build:tracts` locally and commit `public/data/bay-area-tracts.geojson` (or run in CI before build)
4. Deploy — `vercel.json` sets cache headers for static geo data

Shareable URLs:

- Primary: `/?neighbourhood=niles-fremont`
- Legacy (still supported): `/?geoid=06001441301&name=Niles`

## MVP scope

~1,500 census tract polygons across 6 Bay Area counties (internal map engine). Schools and walkability layers use generic placeholders until V2 APIs. Compare areas and national coverage are V2.

To refresh tract boundaries after a Census TIGER update:

```bash
npm run build:tracts
```
